# UI package imports

Next's `experimental.optimizePackageImports` includes `@mairie360/lib-components`. The compiler can optimize imports from the published UI barrel while all frontends keep the exact 0.8.0 release. Module subpaths from the candidate library require its release before adoption.

Validate a clean production build and rendered module interactions when changing this setting. Configuration alone does not establish an initial JavaScript or LCP improvement. The existing performance report records those measurements; proposed budgets remain proposals until the thresholds are accepted.
